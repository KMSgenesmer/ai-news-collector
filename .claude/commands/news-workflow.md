
# 뉴스 수집기 기능 개발 워크플로

AI뉴스 수집기 앱에서 새 기능을 개발할 때 사용하는 워크플로입니다.
브랜치 이름: $ARGUMENTS

## 실행 순서

1. **현재 상태 확인**
   - `git status`와 `git branch --show-current`로 현재 상태와 브랜치를 확인해 줘.
   - main 브랜치가 아니라면 경고를 주고, main으로 이동할지 사용자에게 물어봐 줘. (사용자가 동의하기 전에는 이동하지 마. 커밋되지 않은 변경 사항이 있으면 함께 알려 줘.)

2. **새 브랜치 생성**
   - $ARGUMENTS 로 받은 이름으로 새 브랜치를 만들고 이동해 줘.
   - $ARGUMENTS 가 비어 있다면, 어떤 기능을 개발할 것인지 사용자에게 물어봐 줘. 답변을 바탕으로 영어 소문자-하이픈 형식(예: `add-category-crud`)의 브랜치 이름을 제안하고, 사용자가 확인하면 그 이름으로 만들어 줘.

3. **개발 시작 안내**
   - 브랜치 생성이 끝나면 "이제 개발을 시작하세요!"라고 안내해 줘.
   - CLAUDE.md를 읽고 이 프로젝트의 기술 스택과 컨벤션을 다시 한번 정리해서 알려 줘.
     (예: Next.js / React 버전 주의사항, Tailwind·ui.md 스타일 가이드, 인증·데이터 소유 구조, 사용 가능한 명령어 등)

4. **완료 처리**
   - 사용자가 "완료" 또는 "done"이라고 입력하면:
     1. `git status`와 `git diff --stat`으로 변경된 파일 목록을 보여줘.
     2. 변경 내용을 바탕으로 커밋 메시지를 자동으로 제안해 줘.
     3. 사용자가 확인하면 커밋하고, main으로 이동해 작업 브랜치를 병합해 줘.
   - 사용자가 확인하기 전에는 커밋이나 병합을 하지 마. 병합 중 충돌이 나면 멈추고 사용자에게 알려 줘.

5. **작업 요약**
   - 병합이 끝나면 작업 내용을 요약해서 보여줘. (브랜치 이름, 변경된 파일, 커밋 메시지, 병합 결과)
